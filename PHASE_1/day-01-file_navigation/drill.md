# File Navigation Drill 

Open a terminal, print your working directory, then 
navigate to /var/log using an absolute path, 
back to your home directory using ~, and finally return to /var/log using cd -. List its contents in 
long, human-readable format.

## Steps/Commands

- Open terminal
    - Launch Git Bash/Ubuntu terminal

- Print working directory 
    - pwd

- Navigate to /var/log using absolute path
    - cd /var/log

- Navigate back to home directory 
    - cd ~

- Navigate back to /var/log
    - cd -

- List content with long, human-readable format 
    - ls -lh
