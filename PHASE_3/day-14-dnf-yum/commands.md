# DNF/YUM & Alternative Instals

- "dnf update"
    - This command updates installed packages on systems that use the DNF package manager
    - e.g **"sudo dnf update"**

- "dnf install"
    - This command installs software packages from configured repositories
    - e.g **"sudo dnf install nginx"**

- "dnf remove"
    - This command removes an installed package
    - e.g **"sudo dnf remove nginx"**

- "dnf search"
    - This command is used to search configured repositories for packages matching a term 
    - e.g **"dnf search nginx"**

- "yum install"
    - This command installs packages using the **YUM** package manager
    - e.g **"sudo yum install nginx"**

- "rpm -qa"
    - This command lists all **RPM** packages installed on the system 
    - e.g **"rpm -qa"**

- "snap install"
    - This command installs software distributed as a *Snap Package*
    - Snap is a package format & application distribution system developed by canonical
    - It is commonly available on Ubuntu and can also be installed on other linux distributions
    - e.g **"sudo snap install hello-world"**

- "add-apt-repository"
    - This command adds an APT repository or Personal Package Archive (PPA) to and Ubuntu/Debian-based system
    - e.g **"sudo add-apt-repository ppa:ondrej/php"**

- "dpkg -i"
    - This command installs a local .deb package
    - It is a low-level package mangement system used by Debian & Ubuntu
    - e.g **"sudo dpkg -i myapp_1.0_amd64.deb"**

- "pip / npm install"
    - **"pip"** installs python packages
    - e.g **"python3 -m pip install requests"**
    - **"npm"** installs JavaScript/Node.js packages
    - e.g **"npm install express"**
