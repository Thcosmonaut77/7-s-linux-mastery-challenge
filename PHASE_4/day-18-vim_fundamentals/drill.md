# Vim Fundamentals Drill

Open a new file in vim, type three lines of text, save it, reopen it, delete the middle line, undo the 
deletion, then save and quit.

## Steps/Commands
- Open terminal
    - Launch an ubuntu terminal

- Create a new file in vim
    - vim newfile

- Type three lines
    - i (insert mode)
        - <type three lines of text>

- Save and quit
    - Esc (normal mode)
    - :x

- Reopen file
    - vim newfile

- Delete middle line
    - (in normal mode) move cursor to middle line using arrow keys on keyboard
    - dd

- Undo deletion
    - u

- Save and quit
    - :wq
